# cisa-playground

The `archive/` directory contains earlier drafts and implementation code that were superseded by the actual BIPs [458](https://github.com/bitcoin/bips/pull/2205) (half-aggregation), [459](https://github.com/bitcoin/bips/pull/2210) (full-aggregation), and [460](https://github.com/bitcoin/bips/pull/2212) (CISA for Taproot key path spends).
See [archive/README.md](archive/README.md) for details and for how to run the archived code.
